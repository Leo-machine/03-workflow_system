- 真实进程冒烟（uvicorn + SQLite，模拟容器 entrypoint 流程）：
  1) admin 登录 OK
  2) GET /flows/1 → 10 环节，010 责任人 练宇婷
  3) PUT /assignments/1（owner→贺法）→ {"changed":true,"change_log_id":1}

  6) viewer 改派 → HTTP 403
  7) 同人 no-op → {"changed":false,"change_log_id":null}
